このサイトが集めない情報

  • このサイトには入力欄がありません。名前・メールアドレス・ID・パスワードなどを受け取ることはありません。
  • Cookie を使いません。
  • アクセス解析のツール・広告・外部のフォント・外部のスクリプトを使いません。ページを開いたときに読み込むのは、このサイト自身のファイルだけです。あなたの閲覧の情報を、このサイトから第三者へ送ることはありません。

配信している事業者の記録

このサイトは GitHub 社の GitHub Pages で配信しています。配信の事業者は、安全の確保などのために、アクセスの記録（IP アドレスなど）を取ることがあります。その取り扱いは GitHub 社のプライバシーに関する説明によります。当サイトの運営者は、その記録を受け取っていません。

Google Search Console

当サイトの運営者は、Google 検索でこのサイトが正しく扱われているかを確かめるために、Google 社の Google Search Console を使っています。そのため、トップページに所有者を確かめるための目印（google-site-verification の meta タグ）を1つ置いています。

  • この目印は Google の検索ロボットがページを読みに来たときに使われるだけで、ページを開いたあなたの情報を Google へ送るものではありません。Google のスクリプトも読み込みません。
  • Cookie も使いません。
  • 運営者が Search Console で見られるのは、Google 検索の結果でこのサイトが表示・クリックされた回数などを Google 側で集計したものです。その取り扱いは Google 社のプライバシーに関する説明によります。

リンク先のサイト

このサイトから各社のサイトへのリンクを開くと、その先ではリンク先のサイトの取り扱いに従います。
